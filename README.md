# 🇧🇷 Brasil que Poucos Conhecem

> **Conhecer o Brasil é conhecer as pessoas, histórias e culturas que fazem parte dele.**

## 📖 Sobre o projeto

**Brasil que Poucos Conhecem** é um projeto desenvolvido com o objetivo de apresentar a diversidade cultural brasileira que muitas vezes não recebe a devida atenção da própria sociedade.

O Brasil é formado por diferentes povos, comunidades, histórias, tradições e manifestações culturais. Porém, muitas dessas culturas ainda são pouco conhecidas ou divulgadas.

A proposta do projeto é incentivar as pessoas a **conhecer, respeitar e valorizar a diversidade cultural do Brasil**.

## 🎯 Objetivo

O projeto busca:

* 🇧🇷 Valorizar a diversidade cultural brasileira;
* 📚 Apresentar culturas pouco conhecidas;
* 🤝 Incentivar o respeito às diferentes comunidades;
* 🧠 Aumentar o conhecimento sobre a história e as tradições do Brasil;
* 🚫 Contribuir para a redução do preconceito e da desvalorização cultural;
* 🌎 Mostrar que a cultura brasileira vai muito além do que normalmente é apresentado.

## 🌎 O que você encontrará no site?

O site apresenta informações sobre diferentes culturas e manifestações brasileiras, incluindo:

* 🪶 Culturas indígenas;
* 🖤 Cultura afro-brasileira;
* 🏘️ Comunidades quilombolas;
* 🌊 Cultura caiçara;
* 🚣 Cultura ribeirinha;
* 🌵 Cultura nordestina;
* 🌳 Cultura amazônica;
* 🐎 Cultura sertaneja;
* 🐊 Cultura pantaneira;
* 🎭 Manifestações culturais tradicionais.

Também são apresentadas manifestações como:

* Maracatu;
* Jongo;
* Carimbó;
* Frevo;
* Bumba meu boi;
* Congada;
* Fandango;
* Ciranda;
* Catira;
* Folia de Reis.

## 💡 Por que esse projeto é importante?

Muitas vezes conhecemos apenas algumas manifestações culturais do Brasil, enquanto diversas outras permanecem pouco divulgadas.

A cultura de um país não é formada por apenas uma tradição. Ela é construída por diferentes povos e comunidades ao longo da história.

Por isso, **conhecer outras culturas é uma forma de valorizar a própria identidade brasileira.**

## 💻 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

```text
index.html
```

Não é necessário utilizar banco de dados, backend ou sistema de login.

## 🚀 Funcionalidades

* Navegação entre as seções;
* Design responsivo;
* Animações;
* Cards informativos;
* Curiosidades culturais;
* Botão para descobrir uma cultura aleatoriamente;
* Contador de culturas descobertas;
* Botão para voltar ao topo.

## 🎓 Finalidade

Este projeto possui finalidade **educacional e de conscientização**, buscando incentivar principalmente os jovens a conhecerem melhor a diversidade cultural existente no Brasil.

## ❤️ Mensagem

> **“Que Brasil você ainda não conhece?”**

O objetivo não é apenas apresentar informações, mas despertar a curiosidade para que cada pessoa possa pesquisar, conhecer e valorizar as diferentes culturas que fazem parte do nosso país.
